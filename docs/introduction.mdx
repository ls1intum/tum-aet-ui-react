# TUM AET UI for React

The React design system for applications from Applied Education Technologies (AET) at TUM. It shares design tokens (`--tumaet-ui-*`), class names and light/dark themes with `@tumaet/ui-angular`.

## Install and use

Install the package with `npm install @tumaet/ui-react`. React 19 and React DOM 19 are peer dependencies. Check the changelog before upgrading between 0.x minor releases.

```tsx
import '@tumaet/ui-react/styles.css';
import { Button } from '@tumaet/ui-react';

export function App() {
  return <Button severity="primary">Save changes</Button>;
}
```

Import the stylesheet once. Tokens, base rules and all component styles live in the `tumaet-ui` cascade layer. Declare application layer order before imports so resets stay below the library and overrides stay above it; see the Theming guide for plain CSS and Tailwind examples.

## Principles

- **AET appearance.** Shared tokens and `severity`, `size` and `variant` props define the look. No styling framework is required.
- **React composition.** Native controls supply simple form behavior. Public Base UI primitives supply popup and compound-widget interaction; Base UI is the package's only direct runtime dependency.
- **Application ownership.** Callers own controlled values, application data and validation policy. Component pages document state and empty-value conventions.
- **Accessible composition.** Components provide semantics and keyboard behavior; callers supply names and meaningful content. See the Accessibility page.
