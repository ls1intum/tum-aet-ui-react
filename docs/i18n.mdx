# Texts and localisation

Texts that a component produces itself, such as the label of a close button, "No results found" or the paginator summary, are English by default. Keys look like `tumAetUi.dialog.close` and are the same as in the Angular library. The default catalogue is exported as `DEFAULT_TRANSLATIONS`.

Replace them with `TumAetUiI18nProvider`. Pass a function that turns a key and optional parameters into text, for example from your i18n library. `locale` is used for dates and numbers.

```tsx
import { TumAetUiI18nProvider, DEFAULT_TRANSLATIONS, type Translator, type TranslationKey } from '@tumaet/ui-react';

const de: Partial<Record<TranslationKey, string>> = { 'tumAetUi.dialog.close': 'Schließen' };
const messages: Readonly<Record<string, string | undefined>> = { ...DEFAULT_TRANSLATIONS, ...de };

const translate: Translator = (key, params) =>
  (messages[key] ?? key).replace(/\{(\w+)\}/g, (match, name: string) => String(params?.[name] ?? match));

<TumAetUiI18nProvider translate={translate} locale="de-DE">
  <App />
</TumAetUiI18nProvider>;
```

Keep the default catalogue as a fallback for untranslated component messages. Texts you pass to components yourself, such as labels and placeholders, are not translated by the library.
