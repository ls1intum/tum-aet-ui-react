# Conventions

Component pages document their supported props. The [API policy](https://github.com/ls1intum/tum-aet-ui-react/blob/main/docs/migration-policy.md) defines state ownership, compound parts and collection typing.

- **Element props and refs.** `Input` and `Textarea` forward native props and refs directly. `Checkbox`, `RadioButton` and `ToggleSwitch` refs target their real native inputs. Their `className` and `style` target the visual wrapper (for sizing, layout and descendant styling); all other native props and events target the input. `RadioGroup` props/ref target its fieldset.
- **Boolean controls.** `Checkbox` and `ToggleSwitch` use `checked/defaultChecked/onChange` with native React input events. `RadioGroup` requires a name and reports `onValueChange(value, event)`; option values are strings or numbers. Uncontrolled selection, submission and reset follow HTML/React semantics. Controlled values and reset remain caller-owned.
- **State ownership.** `Select`, `Combobox`, `InputNumber` and `SearchField` require controlled values. Selection components document their empty values. Open/disclosure state follows Base UI's controlled/uncontrolled API. JSX descendants are independently typed; a generic root does not infer types into arbitrary children.
- **Variants are props:** `severity`, `size`, `variant`. They render as `data-*` attributes, which you can use in your own CSS.
- **Icons are `ReactNode`s.** Bring your own icon library or inline SVGs. Icons next to text are decorative; give icon-only buttons an `aria-label`.
- **Popup names.** Give popup lists an accessible name as well as their trigger/input. Reuse the field label ID with `SelectList aria-labelledby` or supply `aria-label`.
- **Forms.** Spread the `FormField` render-function props onto one labelable control to connect its label, hint and error. Flat `Field` parts use explicit `htmlFor`, IDs and ARIA attributes. Validation state and error content belong to the caller; native constraints belong on the control.
- **Style hooks.** Class names start with `tumaet-ui-`; component state and variant attributes can be used in application CSS. Follow the Theming guide for cascade-layer ordering.
